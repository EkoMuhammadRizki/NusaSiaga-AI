## 🌟 Tentang NusaSiaga AI

**NusaSiaga AI** adalah platform *Command Center Kebencanaan* dan *Digital Twin* nasional yang dirancang khusus untuk mengatasi kerentanan wilayah tropis Indonesia. Platform ini mengintegrasikan kecerdasan buatan berbasis spasial (**Geospatial AI**) dengan model simulasi dinamis untuk mendeteksi, memprediksi, dan mensimulasikan skenario bencana alam seperti banjir bandang, tanah longsor, cuaca ekstrem, dan penurunan muka tanah (*land subsidence*) secara real-time.

NusaSiaga AI mengubah paradigma manajemen kebencanaan tradisional: dari yang sebelumnya bersifat **reaktif dan pasif** (hanya merekam kejadian setelah bencana terjadi) menjadi **proaktif, prediktif, dan preventif** melalui visualisasi data 3D interaktif dan automasi keputusan darurat.

---

## 🚨 Urgensi (Mengapa NusaSiaga AI Sangat Dibutuhkan?)

Indonesia terletak di kawasan *Ring of Fire* sekaligus beriklim tropis basah dengan curah hujan ekstrem akibat perubahan iklim global. Urgensi dari kehadiran NusaSiaga AI meliputi:

1. **Frekuensi Bencana Hidrometeorologi yang Meningkat**: Lebih dari 90% bencana di Indonesia didominasi oleh bencana hidrometeorologi (banjir, longsor, puting beliung) yang datang sangat cepat dan mematikan.
2. **Keterbatasan Waktu Respon Operasional**: Tanpa sistem prediksi digital twin, koordinasi evakuasi memakan waktu berjam-jam setelah bencana melanda, yang berujung pada jatuhnya korban jiwa yang seharusnya bisa dihindari.
3. **Penyebaran Peringatan Dini yang Terfragmentasi**: Peringatan dini sering kali tidak terkirim secara tepat sasaran ke wilayah terdampak langsung secara instan.
4. **Perubahan Iklim Global**: Pola cuaca ekstrem yang semakin sulit diprediksi dengan metode konvensional menuntut pemrosesan data spasial multi-layer menggunakan model AI tingkat tinggi.

## 🎯 Tujuan Utama Platform

* **Akurasi Prediksi Multi-Layer**: Memetakan risiko bencana dengan menggabungkan data hidrologi, topografi (DEM), sensor curah hujan, radar BMKG, serta data sosial kependudukan dalam satu tampilan peta tunggal.
* **Simulasi Digital Twin Real-Time**: Menyediakan ruang virtual 3D/2D bagi pembuat kebijakan untuk melakukan simulasi skenario kebencanaan (seperti membuka pintu bendungan atau memicu curah hujan ekstrem) untuk melihat dampak spasial sebelum bencana benar-benar terjadi.
* **Diseminasi Peringatan Dini Omnichannel**: Mengotomatiskan pengiriman peringatan evakuasi multi-channel (SMS Broadcast, Aplikasi Warga, Sirine IoT lokal) langsung dari command center pusat.
* **Kolaborasi Multi-Aktor & Ground Truth**: Menjembatani BNPB, BPBD daerah, operator lapangan, serta laporan warga di satu ekosistem interaktif demi validasi data yang presisi.

## 💻 Tech Stack yang Digunakan

NusaSiaga AI dibangun menggunakan kombinasi teknologi modern untuk menghasilkan antarmuka berkualitas premium, performa tinggi, dan visualisasi spasial yang menakjubkan:

* **Core & Architecture**:
  * **Next.js 14 (App Router)**: Framework React tingkat lanjut untuk performa rendering optimal dan pengelolaan rute yang bersih.
  * **TypeScript**: Menjamin keandalan penulisan kode, kejelasan tipe data, serta kemudahan *maintenance* jangka panjang.
* **Styling & Premium UI Design**:
  * **Tailwind CSS**: Desain responsif, modern, dan sangat konsisten.
  * **Framer Motion**: Animasi mikro, transisi sinematik, serta perpindahan halaman yang halus dan interaktif.
  * **Lucide React**: Set ikon modern yang minimalis dan premium.
* **Visualisasi Data & Peta Spasial**:
  * **Leaflet / React-Leaflet**: Rendering peta interaktif, pemetaan marker risiko spasial, serta visualisasi zona aman secara dinamis.
  * **Recharts**: Representasi data statistik bencana, tren curah hujan, sensor air, dan monitoring logistik dalam bentuk grafik interaktif.
* **Komponen & State**:
  * **Radix UI Primitive Component Layouts**: Digunakan untuk elemen dialog, dropdown, tab, dan navigasi yang aksesibel.

## 🚀 Alur UX Demo & Navigasi Rute

Prototipe ini dirancang sepenuhnya interaktif (*frontend-driven*) dengan alur demo sebagai berikut:

1. **Splash Screen Sinematik (`/`)**
   * Tampilan loading awal yang dramatis mensimulasikan inisialisasi Geospatial Model, sinkronisasi data BMKG & BNPB, serta penghubungan Edge Nodes.
2. **Landing Page (`/`)**
   * Menyajikan visualisasi *workflow*, fitur-fitur unggulan, serta peta risiko awal yang memukau pengguna.
3. **Login Portal (`/login`)**
   * Pintu gerbang masuk ke command center. Pengguna dapat memilih peran simulasi (misal: *BNPB Commander*, *BPBD Operator*, atau *Local Resident*).
4. **Main Command Dashboard (`/dashboard`)**
   * Panel pemantauan real-time nasional. Pengguna dapat mengklik wilayah rawan bencana pada peta interaktif untuk melihat statistik risiko terperinci.
5. **Digital Twin Flood Simulation (`/dashboard/simulation`)**
   * Panel simulasi banjir interaktif di mana pengguna dapat menggeser *slider curah hujan* dan *waktu simulasi* untuk melihat luasan genangan air pada peta digital secara real-time.
6. **Smart Alerts & Emergency Dispatch (`/dashboard/alerts`)**
   * Pusat kendali penyebaran peringatan darurat. Mensimulasikan otorisasi pengiriman sirene kebencanaan dan SMS siaga.
7. **Citizen Crowd-Report Feed (`/dashboard/reports`)**
   * Tampilan laporan visual terkini dari warga lokal di lapangan, lengkap dengan koordinat peta dan status validasi.
8. **Real-time Data Sources Analytics (`/dashboard/data`)**
   * Dashboard pemantauan integritas data spasial, status jaringan sensor IoT, radar BMKG, dan API satelit cuaca.

## ⚙️ Panduan Menjalankan Platform secara Lokal

Pastikan Anda telah menginstal **Node.js** di perangkat Anda sebelum memulai.

1. **Clone Repositori**:
   ```bash
   git clone https://github.com/EkoMuhammadRizki/NusaSiaga-AI.git
   cd NusaSiaga-AI
   ```

2. **Instal Dependensi**:
   ```bash
   npm install
   ```

3. **Jalankan Development Server**:
   ```bash
   npm run dev
   ```

4. **Akses di Browser**:
   Buka [http://localhost:3000](http://localhost:3000) untuk mengeksplorasi seluruh fitur interaktif NusaSiaga AI.
